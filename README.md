# Warestack sales decks

Six self-contained HTML presentations for engineering leaders, platform teams, and security and compliance, in Linear and Jira editions.

Open `index.html` for the deck directory. Use the arrow keys to navigate slides.

## GitHub Pages

Publish from the `main` branch and repository root (`/`). `.nojekyll` keeps the HTML files unchanged.

To update a deck, replace its HTML file under `decks/`, then commit and push to `main`.

The published site is public. Pages include `noindex` metadata, which is not access control.
